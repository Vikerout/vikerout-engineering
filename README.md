# VIKEROUT Engineering — Professional Final Website

Static HTML/CSS website for VIKEROUT Engineering.

## Upload these files
- index.html
- style.css
- logo.svg
- images/vikerout-home.png

## Important
The homepage uses the supplied VIKEROUT image as the hero background. Confirm you have rights to use the image commercially before publishing.

## Free publishing
Upload the files to a public GitHub repository, then enable Settings → Pages → Deploy from a branch → main → / (root).

## Final domain
After testing, a custom domain such as vikerout.com can be connected through GitHub Pages or another static host.
